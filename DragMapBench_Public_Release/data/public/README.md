# Public Data

This directory contains model-facing benchmark inputs:

- `dragmapbench_V5.2_questions.json`: 6,200 core questions.
- `compositional_bundles.json`: 451 compositional diagnostic bundles.
- `counterfactual_triplets.json`: 451 counterfactual diagnostic triplets.
- `answer_format_variants.json`: 2,877 answer-format semantic groups.

The files intentionally omit canonical answers and scoring rules. Private gold
files are distributed separately and belong under `data/private/`.
